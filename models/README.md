# Models

Stage 0 intentionally contains no model files. Future ONNX/ORT models belong
here only when their license, size, and distribution policy are documented.
Large model binaries must remain outside Git history. Stage 5 uses the
externally acquired MobileNetV2 artifact documented in
`docs/REPRESENTATIVE_WORKLOAD.md`; run `scripts/fetch_stage5_assets.ps1` to
download and verify it.
