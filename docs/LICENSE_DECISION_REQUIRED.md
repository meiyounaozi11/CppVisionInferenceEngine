# LICENSE decision required

The repository did not contain a project license at the Stage 8 audit. No
license is therefore implied by the source tree.

For a public portfolio repository, MIT is a reasonable candidate because the
project is an original library and its documented runtime/model/image inputs
have their own third-party terms. Before publishing, the project owner must
choose a license and add the complete license text with the correct copyright
holder. This record deliberately does not make that legal choice on the
owner's behalf.
